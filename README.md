## 🌟 Overview

**Ripple P Electricals** is a premier lighting and electrical supplier in Nairobi, catering to homeowners, contractors, interior designers, and wholesale clients. 

This repository contains the production web platform engineered to transform Ripple P's physical showroom into a modern, mobile-first e-commerce catalog with zero-friction WhatsApp lead conversion.

### 🌐 Live Production URL
👉 **[https://ripplepelectricals.co.ke/](https://ripplepelectricals.co.ke/)**

## 🚀 Key Features

- **📱 Mobile-First Responsive UI**: Built with Tailwind CSS and modern CSS grid/flexbox, optimized for fast loading and smooth navigation across smartphones, tablets, and desktops.
- **⚡ Client-Side Single Page Application (SPA)**: Lightweight vanilla JavaScript state-driven routing (home, products, wholesale, bout, contact) delivering instant tab switching without full page reloads.
- **📦 Multi-Category Product Catalog**:
  - ✨ **Chandeliers**: Crystal, modern minimalist, and luxury ceiling fixtures
  - 💡 **Wall Brackets & Sconces**: Interior and exterior accent lighting
  - 🏮 **Hanging & Pendant Lights**: Dining, kitchen island, and commercial lighting
  - 🔌 **Sockets & Switches (VIP Series)**: Modern tempered glass and metallic luxury plates
  - 🧲 **Magnetic Track Lights & Aluminium Profiles**: Architectural strip and track solutions
  - ☀️ **Panel Lights & Downlights**: Energy-efficient commercial and residential lighting
  - 🛋️ **Decorative & Table Lamps**: Bedside, study, and atmospheric lighting
- **💬 Direct WhatsApp Commerce Pipeline**: Every product card, wholesale request, and consultation link features direct WhatsApp integration (wa.me/254721647578) with pre-composed order details.
- **🔍 Advanced Technical SEO & Schema**:
  - Google Structured Data (schema.org/ElectricalStore) with geo-coordinates, street address, opening hours, and phone contact.
  - Social OpenGraph (og:image, og:title, og:description) and Twitter card tags.
  - Automated sitemap.xml and standard obots.txt configuration for search indexing.
- **🏢 Dedicated Wholesale & Contractor Portal**: Tailored landing section for building contractors, electricians, and bulk buyers with commercial inquiry workflows.

## 💻 Getting Started Locally

### Prerequisites
Any modern browser (Chrome, Edge, Firefox, Safari) and a local development server.

### Running the App
1. Clone the repository:
   `ash
   git clone git@github.com:Djoe5/ripple-p-electricals.git
   cd ripple-p-electricals
   `
2. Serve using VS Code **Live Server** extension, or run a lightweight Python HTTP server:
   `ash
   python -m http.server 8000
   `
3. Open http://localhost:8000 in your web browser.
